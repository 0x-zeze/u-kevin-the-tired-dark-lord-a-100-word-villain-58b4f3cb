# Matron Sorrel and the Tallowgate Grain-Tithe Famine (100 Words)

A deterministic entry for the make.fun bounty **The Tired Dark Lord: A 100-Word Villain Monologue**. It outputs a 100-word (594-byte) first-person monologue spoken by Matron Sorrel, who spent fourteen harvests cornering Tallowgate's grain-tithes and binding three ward-mills in frost-iron—only to offer the hero the entire famine mid-raid.

## Run

```bash
python3 main.py
```

Writes the UTF-8 monologue deterministically (no network, no randomness, no external files) to `/output/entry.txt`.
